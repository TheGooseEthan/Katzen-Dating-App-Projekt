# Katzen-Dating-App-Projekt
Für Informatik Kurs WS26/27 Kollaborative.

Pawfect Coup ist eine Web-Anwendung, die von Swipe-Prinzip von Tinder inspiriert ist und Katzenprofile miteinander verbindet. Das Projekt entsteht im Rahmen des Informatik-Kurses WS 2026/27 als kollaborative Softwareentwicklung von zwei Studenten.

Wichtiger Hinweis: Pawfect Coup ist ein unabhängiges, nicht kommerzielles Studentenprojekt, das ausschließlich zu Bildungs und Studienzwecken entwickelt wird. Es besteht keine Verbindung zu Tinder oder Match Group.

Die Anwendung orientiert sich an allgemeinen Swipe und Matching Konzepten. Name, Logo, Design, und Quellcode werden eigenständig entwickelt. Es werden keine offiziellen Tinder Logos oder geschützten Materialien absichtlich verwendet.


Geplante Funktionen

Katzenprofile mit Foto, Name, Alter, Nationalität, und Charaktereigenschaften
Profile liken und überspringen
Matches bei gegenseitigem Interesse
Benutzerregistrierung und Anmeldung
Profilverwaltung und Match-Statistiken
